# 全站检查与小节版式修整

日期：2026 年 10 月 19 日

## 本次完成

本次按章节重做内页的容器关系。去掉正文外围反复出现的大块底色、整圈边框和投影，改用细线、旁注、段落宽度和留白形成层次。封面、角色图片、棋谱及原有正文继续使用现有资料。

| 章节 | 调整方式 |
| --- | --- |
| 技艺 · 写作 | 将深色侧板改为页边题记，写作过程沿稿纸行线展开；结构说明、篇目和个人记录接续排列。 |
| 技艺 · 诗词 | 移除套在诗卷外面的双层面板，保留竖排意象、朱印与分栏。 |
| 技艺 · 笛子、吉他 | 以气息线、节拍轴、和弦分隔组织内容；拆去练习说明的外层卡片。 |
| 围棋 | 定式入口与对局入口独立但共用连续页面；棋谱、讲解与侧边目录减少外框。手机棋盘新增全局/放大切换。 |
| 文存 | 文章目录沿篇目排列，正文保持窄版阅读，句笺改为页边引句与主题行列。 |
| 作品 | 小说封面与人物肖像作为主体，简介、线索与意象使用章节排版；创作流程页的说明去掉重复面板。 |
| 自我介绍、求学、仰止 | 资料栏使用行线，求学内容采用连续章节，人物侧目录与正文融入同一阅读面。 |
| 志趣 | 保留唱片陈列与实际作品封面，去掉文字说明外的重复容器。 |
| 往来 | 留言沿行线排列；尺素正文呈信纸行线，输入边界与公开/私信选项仍清楚。 |
| 足迹、书卷 | 照片和书封保留明确展示边界，介绍与目录去掉整块面板。 |

物理与宇宙、剪视频、摄影仍走此前保留的设计。相关原有样式和脚本文件已比对，未改写。

## 同时修复的问题

1. 手机展开十九路棋盘后，原先约 731 像素宽，需要横移才能看全。现在默认适配容器；390 像素屏幕下棋盘约 334 像素宽，并可切换放大、查看全局。棋盘仍为 361 个真实落点。
2. 清理歌手信息位置的旧平台整理备注，置顶曲目保留演奏版本说明。已保存封面齐全的歌单不再每次自动重新查询；首次补图只处理仍有缺图的歌单。
3. 将主页联络区的编辑提示换为访客可直接阅读的介绍。
4. 将城市目录的“行旅全录”改为“足迹全录”，与求学行旅区分。
5. 六张小说封面、人物图片另存网页用 WebP，原 PNG 保留。合计从 15,282,043 字节降至 1,258,950 字节，减少约 91.8%。网页、相关资料路径和生成脚本同步更新。
6. 新版章节样式接入页面生成流程，重复执行不再产生额外改动。
