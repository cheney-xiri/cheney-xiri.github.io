## 本地运行

安装 Node.js 24 或更新版本后，在项目目录运行：

```sh
npm start
```

打开终端提示的网址。管理入口为 `/admin/`，首次使用在本机设置站主密码。运行数据保存在 `.site-data/`，不会提交到 GitHub。

## 生成静态预览

```sh
npm run build
```

输出到 `dist/`。上传源代码到 `main` 分支后，GitHub Actions 自动构建并更新预览页。
