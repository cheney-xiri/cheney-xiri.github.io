跟着诗句，进入山河

李白，字太白，号青莲居士，唐代诗人。他的诗以想象丰富、语言明快、情感奔放著称，但并非只有豪迈：孤独、思乡、惜别与失意，也贯穿其中。

与其用单一的“诗仙”形象概括他，不如跟着不同题材阅读。山水诗中的空间、送别诗中的目光、饮酒诗中的转折，呈现的是同一位诗人的不同侧面。

山水与归途 / 七言绝句 / 全文

早发白帝城

朝辞白帝彩云间，千里江陵一日还。两岸猿声啼不住，轻舟已过万重山。

全诗从启程写到穿行万山，空间跨度很大，阅读感受却异常轻快。“一日”“已过”推动速度，“猿声”仍在耳边而舟已远去，声音与行动的错位让行程更鲜明。

友人与远行 / 七言绝句 / 全文

黄鹤楼送孟浩然之广陵

故人西辞黄鹤楼，烟花三月下扬州。孤帆远影碧空尽，唯见长江天际流。

诗从人物、地点和季节起笔，后两句把目光停留在渐远的帆影上。告别没有直接写成悲伤，而是化为长久凝望：人已远去，江水仍向天边流。

独处与山 / 五言绝句 / 全文

独坐敬亭山

众鸟高飞尽，孤云独去闲。相看两不厌，只有敬亭山。

鸟与云相继离开，诗的空间渐渐安静。后两句把山写成可以相对的对象，使“独坐”转为一种人与自然的相伴。它与李白诗中的壮阔声调不同，更显沉静。

月色与故乡 / 五言绝句 / 全文

静夜思

床前明月光，疑是地上霜。举头望明月，低头思故乡。

四句中只有很少的动作：看见、疑惑、抬头、低头。由光到霜的联想，再由月色到故乡的转变，让思乡不是抽象的抒情，而是一个夜里自然发生的念头。此处采用通行本。

乐府歌行 / 酒与时间 / 全文

将进酒

君不见黄河之水天上来，奔流到海不复回。君不见高堂明镜悲白发，朝如青丝暮成雪。人生得意须尽欢，莫使金樽空对月。天生我材必有用，千金散尽还复来。烹羊宰牛且为乐，会须一饮三百杯。岑夫子，丹丘生，将进酒，杯莫停。与君歌一曲，请君为我倾耳听。钟鼓馔玉不足贵，但愿长醉不愿醒。古来圣贤皆寂寞，惟有饮者留其名。陈王昔时宴平乐，斗酒十千恣欢谑。主人何为言少钱，径须沽取对君酌。五花马，千金裘，呼儿将出换美酒，与尔同销万古愁。

开头把黄河奔流与人生衰老相对，先将情绪推向时间不可挽回的紧迫。饮酒的欢畅中不断出现寂寞与不平，结尾又落在“愁”上。因此，它的情绪有高低与往复，并不是从头到尾只有豪迈。诗句传本存在异文，此处采用通行文本。

乐府 / 失意与自勉 / 全文

行路难·其一

金樽清酒斗十千，玉盘珍羞直万钱。停杯投箸不能食，拔剑四顾心茫然。欲渡黄河冰塞川，将登太行雪满山。闲来垂钓碧溪上，忽复乘舟梦日边。行路难，行路难，多歧路，今安在？长风破浪会有时，直挂云帆济沧海。

珍贵的酒食没有带来欢欣，反而引出停杯、拔剑与茫然。冰河雪山将阻碍写成可见的地形；垂钓和乘舟的典故又重新打开希望。末句的自勉，是在前面的犹疑与阻力中形成的，不能省去中间的曲折。

五言古诗 / 月与孤独 / 全文

月下独酌·其一

花间一壶酒，独酌无相亲。举杯邀明月，对影成三人。月既不解饮，影徒随我身。暂伴月将影，行乐须及春。我歌月徘徊，我舞影零乱。醒时同交欢，醉后各分散。永结无情游，相期邈云汉。

月与影由景物变成“同伴”，又被诗人指出无法真正相知。想象中的热闹与现实的独酌相互交错，结尾将相约之地推向云汉，扩大了诗的空间，也保留了最初的孤独。

五言律诗 / 惜别 / 全文

送友人

青山横北郭，白水绕东城。此地一为别，孤蓬万里征。浮云游子意，落日故人情。挥手自兹去，萧萧班马鸣。

青山、白水先构成明晰的送别地点，随后以孤蓬、浮云、落日对应远行与留恋。最后让马鸣收束全诗，人的不舍不再直说，而由声音延续。

五言律诗 / 出蜀远行 / 全文

渡荆门送别

渡远荆门外，来从楚国游。山随平野尽，江入大荒流。月下飞天镜，云生结海楼。仍怜故乡水，万里送行舟。

山峦消失、平野展开，写的是行舟中不断改变的视野。后两联由月与云的奇景回到故乡之水，把地理上的离开写成情感上的相送。

七言绝句 / 山水 / 全文

望庐山瀑布

日照香炉生紫烟，遥看瀑布挂前川。飞流直下三千尺，疑是银河落九天。

“遥看”确定了远望的视点，“挂”先把瀑布写成整体，随后“飞流直下”使画面运动起来。末句以银河的想象扩展尺度，三千尺是诗歌中的夸张，不能当作测量数据。

七言绝句 / 江行 / 全文

望天门山

天门中断楚江开，碧水东流至此回。两岸青山相对出，孤帆一片日边来。

两岸山峰的“出”，与行舟中变化的视角有关。诗没有静止地罗列山水，而是以江流、山形和帆影建立一个正在展开的场景。

七言绝句 / 初行与思念 / 全文

峨眉山月歌

峨眉山月半轮秋，影入平羌江水流。夜发清溪向三峡，思君不见下渝州。

峨眉山、平羌江、清溪、三峡、渝州连续出现，却没有变成地名清单。月与江水把空间串联，最后一句将远行与思念连在一起。

七言绝句 / 寄友 / 全文

闻王昌龄左迁龙标遥有此寄

杨花落尽子规啼，闻道龙标过五溪。我寄愁心与明月，随君直到夜郎西。

杨花与子规先建立暮春气氛，再转到友人的远谪。月亮被赋予传递愁心的能力，使两地不能相见的现实转化为共同面对的天空。末句存在“随风”等异文，此处取通行本“随君”。

七言绝句 / 送别 / 全文

赠汪伦

李白乘舟将欲行，忽闻岸上踏歌声。桃花潭水深千尺，不及汪伦送我情。

诗从“将欲行”的具体时刻写起，以意外听到的踏歌声引出送别。“深千尺”是夸张，而“不及”又把可测的水深与不可测的友情并置。

七言绝句 / 酒与客居 / 全文

客中作

兰陵美酒郁金香，玉碗盛来琥珀光。但使主人能醉客，不知何处是他乡。

前两句调动嗅觉与视觉，把酒写得具体可感；后两句才转入客居的心情。这里短暂忘却他乡，不等于李白的诗从无思乡，而是这一首作品中的特定情境。

七言绝句 / 笛声与故园 / 全文

春夜洛城闻笛

谁家玉笛暗飞声，散入春风满洛城。此夜曲中闻折柳，何人不起故园情。

笛声先是找不到来处的“暗飞声”，随后随着春风遍布城中。《折杨柳》的曲调带出送别与思乡传统，听觉成为从眼前夜景进入故园记忆的通道。

七言绝句 / 山居 / 全文

山中问答

问余何意栖碧山，笑而不答心自闲。桃花流水窅然去，别有天地非人间。

问句要求一个理由，回答却先以笑和沉默出现。后两句让桃花流水代为呈现山中世界，说明不靠议论完成，而由景物承接。

古体诗 / 忧思与逸兴 / 全文

宣州谢朓楼饯别校书叔云

弃我去者，昨日之日不可留；乱我心者，今日之日多烦忧。长风万里送秋雁，对此可以酣高楼。蓬莱文章建安骨，中间小谢又清发。俱怀逸兴壮思飞，欲上青天揽明月。抽刀断水水更流，举杯销愁愁更愁。人生在世不称意，明朝散发弄扁舟。

全诗的情绪变化十分剧烈：由开篇的烦忧，转入登楼时的高逸，再由揽月的想象跌回现实中的愁。抽刀断水以动作的不可能性写出无法简单排遣的烦恼；末句是对另一种生活的想象，而非已经发生的行程记录。

蜀道难

噫吁嚱！危乎高哉！蜀道之难，难于上青天！蚕丛及鱼凫，开国何茫然！尔来四万八千岁，不与秦塞通人烟。西当太白有鸟道，可以横绝峨眉巅。地崩山摧壮士死，然后天梯石栈相钩连。上有六龙回日之高标，下有冲波逆折之回川。黄鹤之飞尚不得过，猿猱欲度愁攀援。青泥何盘盘！百步九折萦岩峦。扪参历井仰胁息，以手抚膺坐长叹。问君西游何时还？畏途巉岩不可攀。但见悲鸟号古木，雄飞雌从绕林间。又闻子规啼夜月，愁空山。蜀道之难，难于上青天，使人听此凋朱颜！连峰去天不盈尺，枯松倒挂倚绝壁。飞湍瀑流争喧豗，砯崖转石万壑雷。其险也若此，嗟尔远道之人胡为乎来哉？剑阁峥嵘而崔嵬，一夫当关，万夫莫开。所守或匪亲，化为狼与豺。朝避猛虎，夕避长蛇。磨牙吮血，杀人如麻。锦城虽云乐，不如早还家。蜀道之难，难于上青天，侧身西望长咨嗟！

空间的伸缩

“千里”“万重山”等词把空间骤然拉大，再以舟、帆或月色将它收进眼前。

情绪的转折

豪迈与失意常出现在同一首长诗中。读《将进酒》或《行路难》时，不妨标出语气变化的位置。

声音与节奏

先按句读，再轻声吟诵；长短句、重复与夸张，都能从声音中被感受到。
