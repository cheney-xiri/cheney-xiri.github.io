从文字看思想与气象

毛泽东的诗词、文章与书法，提供了三种不同的阅读方式：诗词以山河与历史展开情感，文章围绕现实问题组织论证，书迹则保留了文字形成时的节奏。

读这一人物，需要把作品放回具体年代：从求学、革命战争到中华人民共和国成立后的历史，既看到其历史作用，也正视“大跃进”和“文化大革命”造成的严重后果。

精神与品格

依据文献中的明确表述选录；各条分别注明依据与适用语境。

思想方法 / 文献要点

实事求是

1981 年《关于建国以来党的若干历史问题的决议》将实事求是概括为从实际出发、使理论与实际相联系，并把调查研究和实践检验放在重要位置。此处依据该文献整理这一方法，不把“相信自己”直接当作它的定义。

依据：《关于建国以来党的若干历史问题的决议》第（30）部分 ↗

人民立场 / 原文节录

为人民服务

只要你说得对，我们就改正。

这句话出自 1944 年《为人民服务》，其上下文讨论如何面对批评、改正缺点。文中的出发点是人民利益，不能把它截成脱离对象与条件的一般成功学格言。

依据：《为人民服务》相关原文摘录 ↗

立场与方法 / 文献要点

独立自主

1981 年历史决议强调立足中国实际、依靠本国人民探索道路，同时明确需要学习外国有益的先进事物。因此，独立自主与自力更生不能被曲解为闭关自守或拒绝学习。

依据：《关于建国以来党的若干历史问题的决议》第（30）部分 ↗

工作作风 / 原文节录

谦虚谨慎与艰苦奋斗

务必使同志们继续地保持艰苦奋斗的作风

这一要求提出于 1949 年党的七届二中全会，背景是革命胜利前夕以及即将面对的建设任务。同一段还强调谦虚、谨慎、不骄、不躁，应把这些要求联系起来理解。

1919年10月8日 / 四言诗 / 全文

四言诗·祭母文

呜呼吾母，遽然而死。寿五十三，生有七子。七子余三，即东民覃。其他不育，二女二男。育吾兄弟，艰辛备历。摧折作磨，因此遘疾。中间万万，皆伤心史。不忍卒书，待徐温吐。今则欲言，只有两端。一则盛德，一则恨偏。吾母高风，首推博爱。远近亲疏，一皆覆载。恺恻慈祥，感动庶汇。爱力所及，原本真诚。不作诳言，不存欺心。整饬成性，一丝不诡。手泽所经，皆有条理。头脑精密，劈理分情。事无遗算，物无遁形。洁净之风，传遍戚里。不染一尘，身心表里。五德荦荦，乃其大端。合其人格，如在上焉。恨偏所在，三纲之末。有志未伸，有求不获。精神痛苦，以此为卓。天乎人欤？倾地一角。次则儿辈，育之成行。如果未熟，介在青黄。病时揽手，酸心结肠。但呼儿辈，各务为良。又次所怀，好亲至爱。或属素恩，或多劳瘁。大小亲疏，均待报赍。总兹所述，盛德所辉。必秉悃忱，则效不违。致于所恨，必补遗缺。念兹在兹，此心不越。养育深恩，春晖朝霭。报之何时？精禽大海。呜呼吾母，母终未死。躯壳虽隳，灵则万古。有生一日，皆报恩时。有生一日，皆伴亲时。今也言长，时则苦短。惟挈大端，置其粗浅。此时家奠，尽此一觞。后有言陈，与日俱长。尚飨！

1925年 / 词 / 全文

沁园春·长沙

独立寒秋，湘江北去，橘子洲头。看万山红遍，层林尽染；漫江碧透，百舸争流。鹰击长空，鱼翔浅底，万类霜天竞自由。怅寥廓，问苍茫大地，谁主沉浮。携来百侣曾游，忆往昔峥嵘岁月稠。恰同学少年，风华正茂；书生意气，挥斥方遒。指点江山，激扬文字，粪土当年万户侯。曾记否，到中流击水，浪遏飞舟。

这一段由山林写到江面，颜色从“红”转到“碧”，视线也由岸上移向水中。“万”“层”“漫”“百”使景物具有铺展感，而“染”“争”等动词让秋景充满运动。全词上阕从眼前山河提出追问，下阕转入对青年同伴与往事的回忆。

1928年秋 / 词 / 全文

西江月·井冈山

山下旌旗在望，山头鼓角相闻。敌军围困万千重，我自岿然不动。早已森严壁垒，更加众志成城。黄洋界上炮声隆，报道敌军宵遁。

1929年 / 词 / 全文

采桑子·重阳

人生易老天难老，岁岁重阳，今又重阳，战地黄花分外香。一年一度秋风劲，不似春光，胜似春光，寥廓江天万里霜。

全词以人的易老与自然的长久起笔，再把重阳节的秋景写成开阔的江天。“不似”与“胜似”先否定、再翻转，让秋不只是衰落的季节。这里的“劲”与“寥廓”是理解词中声音和空间的关键。

1933年 / 词 / 全文

菩萨蛮·大柏地

赤橙黄绿青蓝紫，谁持彩练当空舞？雨后复斜阳，关山阵阵苍。当年鏖战急，弹洞前村壁。装点此关山，今朝更好看。

词以雨后彩虹起笔，由设问把自然景象写得灵动。后文回忆战地，并看见村壁上的弹痕；眼前风景与往日经历由此叠合。阅读的重点是两层时间怎样在同一个地点相遇。

1935年 / 词 / 全文

忆秦娥·娄山关

西风烈，长空雁叫霜晨月。霜晨月，马蹄声碎，喇叭声咽。雄关漫道真如铁，而今迈步从头越。从头越，苍山如海，残阳如血。

上阕写风、雁声、霜月、马蹄与喇叭，声音和冷色景物相互映照。下阕由关隘之险转入行动，再以山色与夕阳收束。读这首词时，既要保留战争情境，也应区分自然景物的描写与后人的象征性阐释。

1935年 / 七言律诗 / 全文

七律·长征

红军不怕远征难，万水千山只等闲。五岭逶迤腾细浪，乌蒙磅礴走泥丸。金沙水拍云崖暖，大渡桥横铁索寒。更喜岷山千里雪，三军过后尽开颜。

全诗将漫长行军压缩进八句：五岭、乌蒙、金沙江、大渡河、岷山依次出现。颔联以“细浪”“泥丸”写山，颈联用“暖”“寒”造成对比；这些写法与实际艰难并置，构成诗的张力。不能把文学中的夸张，直接当作现实困难很轻微的陈述。

1935年10月 / 词 / 全文

清平乐·六盘山

天高云淡，望断南飞雁。不到长城非好汉，屈指行程二万。六盘山上高峰，红旗漫卷西风。今日长缨在手，何时缚住苍龙？

词中将天高、云淡、南飞雁与行军场景并置。“屈指”是回顾行程的动作，使遥远的空间成为可以追数的经历。下阕再写山峰、红旗与行动意志，形成由远望到近景的转换。

1936年2月 / 词 / 全文

沁园春·雪

北国风光，千里冰封，万里雪飘。望长城内外，惟余莽莽；大河上下，顿失滔滔。山舞银蛇，原驰蜡象，欲与天公试比高。须晴日，看红妆素裹，分外妖娆。江山如此多娇，引无数英雄竞折腰。惜秦皇汉武，略输文采；唐宗宋祖，稍逊风骚。一代天骄，成吉思汗，只识弯弓射大雕。俱往矣，数风流人物，还看今朝。

上阕以雪景构成辽阔空间，长城、大河、群山和高原依次进入画面；下阕由山河转入历史人物的评论。“望”领起观景，“惜”领起评议，景与史通过换阕相接。阅读末句时应结合全篇及作者相关说明，不擅自把“风流人物”缩成某一个人的指代。

据站主提供的诗词资料校录。

1937年4月 / 四言诗 / 全文

四言诗·祭黄帝陵

赫赫始祖，吾华肇造。胄衍祀绵，岳峨河浩。聪明睿知，光被遐荒。建此伟业，雄立东方。世变沧桑，中更蹉跌。越数千年，强邻蔑德。琉台不守，三韩为墟。辽海燕冀，汉奸何多！以地事敌，敌欲岂足？人执笞绳，我为奴辱。懿维我祖，命世之英。涿鹿奋战，区宇以宁。岂其苗裔，不武如斯：泱泱大国，让其沦胥？东等不才，剑屦俱奋。万里崎岖，为国效命。频年苦斗，备历险夷。匈奴未灭，何以家为？各党各界，团结坚固。不论军民，不分贫富。民族阵线，救国良方。四万万众，坚决抵抗。民主共和，改革内政。亿兆一心，战则必胜。还我河山，卫我国权。此物此志，永矢勿谖。经武整军，昭告列祖。实鉴临之，皇天后土。尚飨！

文章里的问题与方法

四篇文章分别处理什么问题，又怎样展开论证。

1930 / 调查研究

反对本本主义

这篇文章批评脱离实际的本本主义，提出调查对于了解情况、形成判断的重要性。文章的论证不是排斥书本，而是反对用书本中的现成结论代替对中国具体情况的研究。

问题从哪里来
文章围绕实际工作中不了解情况、照搬结论的做法展开，调查是解决问题的起点。
与实事求是的联系
把事实情况作为判断依据，是理解其调查研究主张的重要线索。不能把它简化成“经验永远比理论正确”。

1937 / 认识与实践

实践论

《实践论》讨论认识从何而来、如何发展，以及认识怎样回到实践。文章把感性认识、理性认识和实践之间的联系组织成一个发展过程。

核心关系
从接触具体事物、形成经验，到把握联系与规律，再回到实践接受检验，认识并不止于一次观察。
阅读时的边界
“实践”在文中有明确的社会历史含义，不能直接等同于任何一次个人尝试，也不能用一时成败替代对真理标准的讨论。

1937 / 普遍性与特殊性

矛盾论

文章讨论矛盾的普遍性、特殊性，主要矛盾与矛盾的主要方面，以及矛盾双方的关系。它要求对不同过程、不同阶段中的具体情形作具体分析。

两组区别
主要矛盾不是矛盾的主要方面：前者比较不同矛盾的地位，后者讨论同一矛盾双方的作用。
与研究方法的联系
概念应服务于分析具体问题，而不是成为给任何现象贴标签的通用套话。

1938 / 战争条件与发展阶段

论持久战

《论持久战》分析中日双方的条件，反对亡国论与速胜论，并讨论战争发展的阶段。其判断建立在战争性质、双方力量与变化趋势的分析之上。

文章怎样展开
先回答能否胜利、为何持久，再讨论阶段、主动性与人的作用，形成由条件到策略的论证链条。
放回历史语境
这是一篇针对抗日战争的军事论述。应用其中的方法，应先理解其当时所分析的对象与条件。

书法：看字，也看章法

行草的节奏

可先观察字与字之间的连断、大小对比和行气，再读单字结构。诗词手稿与题字的用途不同，阅读书迹时也应区别看待。

修改、增删与重写是手稿的一部分。把书写视为文字形成的过程，往往比只看字形更有意思。
